- The guided bootstrap pairing code is delivered as a `0600` file (`<stateDir>/bootstrap-paircode.txt`) since 2026-08-23 (batch B-1); logs carry only the path. - Bounded in-memory learning tables landed 2026-08-24 (batch B-k4 / P1-7, `src/inbound/_bounded.mjs`): dingtalk `sessionWebhooks`/`chatSenders`/`seenMsgIds` and qq `targetKinds`/`msgSeqs` cap at 1024 with LRU touch; `wechat:ctx:` caps at 256 uids in first-seen order; `createTrailingDebounce`/`createGraceQueue` cap at 256 in-flight keys and fire the oldest early instead of dropping it. Accepted for now (ctx is a cache with a working fallback), pinned by test, and recorded as a residual gap in the handoff tech-debt ledger.

In particular, do not copy unlicensed community iLink clients or `UNLICENSED` QQ connectors; optional SDKs must remain lazy and non-mandatory.
